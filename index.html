Exécution chez vous si besoin

Le pipeline est un programme Python qui tourne sur un poste ou une machine virtuelle de votre environnement. Vos fichiers ne quittent pas votre système d'information.

Aucun calcul ne passe par un modèle de langage. Les livrables (bilan, tableau de bord, registre des chiffres) vous sont remis et restent les vôtres.

Ce que le bilan ne garantit pas

  • Les économies sont des estimations en fourchette, fondées sur des hypothèses que nous validons ensemble.
  • La valeur repose sur des heures économisées déclarées par les équipes, valorisées à un coût horaire convenu avec vous : elle n'est pas auditée. Les décisions par cas d'usage sont des propositions pour votre comité.
  • Le budget 2027 est calculé à volumes constants : la croissance des usages et les nouveaux projets s'ajoutent.
  • La lecture du Data Act est opérationnelle, à faire confirmer par votre juriste.
  • Le recalcul indépendant prouve que le code applique les définitions écrites, pas que ces définitions sont les bonnes : c'est l'objet de l'échange avec vous.
